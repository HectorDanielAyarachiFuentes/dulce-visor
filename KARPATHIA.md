# Principios Karpathy (Agentic Engineering) para Dulce-Visor

1. **No Silent Assumptions**: Verificar la causa raíz exacta (por qué Windows 11 oculta las ventanas flotantes).
2. **Minimal & Clean Code**: Cero código de relleno, cero bibliotecas pesadas que no se necesiten.
3. **Surgical Fix**: Arreglar la causa exacta sin romper lo que ya funciona bien (diseño de ondas, CPU, GPU, RAM y botón boost).
4. **Permanent Robustness**: La ventana debe resistir eventos de Shell (Inicio, Win+D, apertura de apps) sin parpadeo.
